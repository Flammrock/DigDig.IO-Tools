# Example scan

Download [digdig-map.chunks](digdig-map.chunks?raw=1) and open it in Map Observatory with **☰ → Files → Preview .chunks**. A running game and userscript are not required to explore a saved scan.

This sample contains **289 terrain chunks** and no markers. It retains the captured world coordinates, material pixels, build fingerprint, and saved map bounds. You can pan, zoom, add your own markers, and save an edited copy.

The accompanying [PNG](../docs/assets/explored-map.png) is a **1280 × 1216** export of this exact scan. It preserves transparent unknown areas and contains no player marker or interface overlays. The [demo GIF](../docs/assets/live-scan.gif) shows the browser on the left and desktop app on the right.

To combine this file with a compatible live scan, use **Load .chunks** instead of Preview. Existing observed pixels take priority. Captured material locations describe the recorded game world; they are not a current map of every server.

The demo and sample scan were supplied by Flammrock. The original GIF, PNG, and `.chunks` bytes are preserved in this repository.
